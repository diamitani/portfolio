02 · CORE SYSTEMS

Six production systems, running today

Not demos. These are the revenue workflows I design, build, and keep alive in production CRMs.

SYSTEM 01

Inbound Engine

Webhook listener catches every inquiry → enrichment → LLM ICP scoring → sub-30-second round-robin calendar booking. Recovered 364 historical chatbot contacts into attribution with a zero-error API backfill.

101 MQLs · 29 deals · $6.38M pipeline
SYSTEM 02

Prospect Engine

Intent waterfall: hiring and tech-stack signals → CRM dedupe shield → multi-provider enrichment → personalized sequences. 8-signal library with a 0–100 account scoring model; 5,398-contact master run in weekly CRM-safe batches.

8 hrs / 50 accounts → under 30 min · opens 17% → 55%
SYSTEM 03

Pre-Sales Dossiers

Ten minutes before every discovery call, the rep gets a one-pager in Slack: prospect bio, recent news, tech stack, tailored questions. Triggered off the meeting-booked webhook and enriched with intent data.

Requested by VP Growth · fully automated
SYSTEM 04

Post-Sales Intelligence

Transcript webhooks → AI extraction of BANT criteria, competitors, and next steps → CRM deal-stage updates → follow-up drafts. Repaired a pipeline failing on 21 of 25 runs; cut per-call context bloat 882KB → 295KB.

EOR Compliance Checker: 46 nodes, 242 deals screened, 103 corrected
SYSTEM 05

Daily Execution Digest

7:30 AM, every day: overdue deal stages, uncontacted demo requests, ghosting alerts. The hygiene report that keeps a pipeline honest, with zero rep effort.

Daily · automated · zero rep effort
SYSTEM 06

Executive GTM Telemetry

6:00 PM briefing: new pipeline generated, stage conversion, velocity. The daily picture of the revenue engine, in one place, for the people who own the number.

Twice-daily loop · live dashboard

The governance layer underneath all six

Enrichment with spend controls. Clay + Python + Amplemarket + ZoomInfo + HubSpot waterfall with deduplication and credit governance: cut third-party data spend ~70% across 10,000+ accounts, traced a 515K-credit monthly spike to its sources, shipped reusable guardrails. Email verification pipeline: web-search scraper → syntax guess → MX verify — 492 of 500 pass before anything sends.

Approval gates on every external send. Nothing goes out without a human gate. Compliance posture built in by default, not bolted on.
